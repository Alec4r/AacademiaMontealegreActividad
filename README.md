# Academia Horizonte — Certificados automáticos

Caso **ficticio** creado para una actividad interna de activación del valor **Quality** de edunext.

"Academia Horizonte" es una academia de cursos online inventada para este ejercicio. Este repositorio
simula un sistema simple que decide si un/a estudiante recibe un certificado al finalizar un curso y,
si corresponde, lo "envía" (simulado con un `print`, sin integraciones reales).

El objetivo de la actividad es practicar revisión de código y pruebas automatizadas: la rama `main`
contiene la versión base (sin la lógica de certificación todavía), y la rama `feature/certificados`
es el Pull Request a revisar.
